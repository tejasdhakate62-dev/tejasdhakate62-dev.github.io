🔗 **Live Link:** [tejasdhakate62-dev.github.io](https://tejasdhakate62-dev.github.io)

---

## ✨ Design & Architectural Features

*   **Glassmorphism UI (`.glass`):** Built utilizing custom backdrop-filters (`blur(15px)`) and dynamic hover transformations (`translateY(-10px) rotateX(3deg)`) to create a floating, modern card layer.
*   **3D Torus Knot Animation:** Powered by **Three.js** to render an interactive, responsive wireframe element that dynamically floats based on real-time execution loops.
*   **Intersection Observer API:** Custom lazy-trigger mechanism built in vanilla JavaScript to smoothly animate tech proficiency progress bars only when they enter the user's viewport.
*   **Document Grid Integration:** Custom cloud/local assets grid highlighting academic presentations, bootcamp validations, and national conference certificates.
*   **Responsive Layout:** Fully styled with **Tailwind CSS**, offering seamless media breakpoint transitions (`sm:`, `md:`, `lg:`) for desktops, tablets, and smartphones.

```text
💻 Local Setup & Development Instructions
To clone the workspace and test updates locally on your system:

Clone the Repository:

Bash
    git clone [https://github.com/tejasdhakate62-dev/tejasdhakate62-dev.github.io.git](https://github.com/tejasdhakate62-dev/tejasdhakate62-dev.github.io.git)
    cd tejasdhakate62-dev.github.io
    ```

2.  **Launch a Local Environment:**
    *   If using **VS Code**, right-click `index.html` and choose **Open with Live Server**.
    *   Alternatively, run a Python quick server inside the directory:
```bash
        python -m http.server 5500
        ```
    *   Open your browser and navigate to `http://127.0.0.1:5500`.

3.  **Deploying Updates:**
```bash
    git add .
    git commit -m "Refactor: Update documents matrix structure"
    git push origin main
    ```
